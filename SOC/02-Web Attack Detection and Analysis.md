C**ourse Completion: Detecting Web Attacks
🛡️ Overview**
This repository documents my progress and completion of the "Detecting Web Attacks" course on LetsDefend. This course focused on identifying, analyzing, and understanding common web-based attack vectors that target web applications and servers in a Security Operations Center (SOC) environment.
🔍 **Key Learning Objectives & Topics Covered**
Common Web Vulnerabilities: Learning how attackers exploit web applications (e.g., understanding attack signatures and payloads).

HTTP Traffic Analysis: Analyzing web server logs and HTTP requests to spot malicious activities.

Incident Investigation: Identifying anomalies in web traffic, tracking attacker behaviors, and distinguishing between normal user traffic and active web exploits.

🚀 Why This Matters
Web applications are often the primary entry point for external attackers. Mastering the detection of web attacks enables a SOC analyst to respond swiftly to SQL injections, Cross-Site Scripting (XSS), directory traversal, and other application-layer threats before they compromise core network assets.
